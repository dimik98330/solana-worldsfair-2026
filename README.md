# Solana World's Fair 2026 — исследование

Приватное рабочее пространство `dimik98330` для первого Solana-проекта.

Сейчас выполняется только промпт 1: среда, ProofPilot, условия конкурса и отбор идеи. Идея ещё не утверждена; приложение, архитектура и финальная заявка не созданы.

Начните с [AGENTS.md](AGENTS.md), [стартовых инструкций](CODEX_SOLANA_WORLDSFAIR_START.md) и [состояния](docs/00-STATE.md). Продуктовые решения требуют ProofPilot; разработка, дизайн и проверки — соответствующих установленных скиллов.

Документы: [условия и сроки](docs/01-HACKATHON.md), [среда и каталог скиллов](docs/02-ENVIRONMENT.md), [идеи](docs/03-IDEAS.md), [источники](docs/04-EVIDENCE.md), [ревью](docs/05-REVIEW.md), [решение и эксперимент](docs/06-DECISION.md).

[Локальный HTML-отчёт](docs/RESEARCH.html) — представление исследования, не интерфейс продукта. Откройте его как обычный файл; пересборка из Markdown: `node scripts/build-research-report.mjs`. Восстановление инструментов описано в [docs/setup](docs/setup/README.md); текущая установка повторного запуска не требует.

Разрешены только бесплатные инструменты и будущие localnet/devnet-проверки. Ключи, credentials, локальные MCP-конфиги и установленные скиллы исключены из Git. Публикация репозитория и финальная подача требуют отдельной команды.

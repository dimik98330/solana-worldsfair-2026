## Вывод

**Не туннелировать существующий owner API на :3000.** Бесплатный кратковременный interactive demo технически возможен как отдельный **guided localnet sandbox** с новым storage/signers и отдельным validator ledger, строгими public HTTP gates и ограниченным guest writer. Постоянная конкурсная ссылка должна вести на отдельный source-only public repo/Pages с видео и воспроизведением; временный sandbox — дополнительный реально работающий путь, а не обещание постоянного hosted backend.

Без описанных ниже изменений сейчас готов только source/video/read-only путь. Devnet deployment остаётся отдельным funding blocker; наличие tunnel не превращает localnet в devnet. New sandbox/public gateway ещё не реализован и не проверен этим аудитом. Original repo stays private; публичные действия выполняет lead лишь в действительной scoped owner authorization.

## Проверенные варианты

Первичные официальные docs прочитаны **8 октября 2026**:

| Вариант | Что реально получит жюри | Ограничение/решение |
|---|---|---|
| GitHub Pages, отдельный safe source repo | Постоянный HTML/video/evidence, доступ к коду, инструкции локального запуска | Static hosting; не запускает Node/SQLite/validator и не исполняет corporate actions. GitHub Free допускает Pages из public repositories. Подходит как основная release ссылка. [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) |
| Cloudflare Quick Tunnel → isolated demo mode | Временный HTTPS интерфейс, actual guided test transactions на локальном sandbox validator | Не нужен Cloudflare account/domain. URL действует пока процесс работает; hostname меняется при новом запуске, uptime guarantee отсутствует; 200 in-flight requests, без SSE. Поэтому подходит как дополнительный временный demo, после HTTP/isolation work. [Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/) |
| Render Free → текущий backend | Node service можно запустить, но нынешнее durable state/key/validator устройство не переносится без изменений | Free service засыпает через15min idle; restart/spindown/redeploy теряют SQLite/local files, persistent disk недоступен. Нельзя честно заявить текущую recovery durability после прямого переноса. [Render Free](https://render.com/docs/free) |
| Quick Tunnel → GET-only sanitized gateway | Live таблицы/сверка настоящего localnet state, current clock/slot и сохранённые receipts | Нет create/claim/vote/redeem. Это useful live read-only verification, **не полноценное интерактивное приложение**. Допустимый fallback при недостатке ресурсов для sandbox, с явной маркировкой |

Новые Cloudflare docs описывают `--allowed-mail` и browser email PIN gate. Judge addresses/domain неизвестны; installed binary/flag compatibility не проверена, `cloudflared` не найден в текущем Windows PATH. Это optional restricted-access вариант, а не готовая integrated auth. Не устанавливать/изменять account config в рамках данного read-only аудита. Официальный [Downloads](https://developers.cloudflare.com/tunnel/downloads/) указывает maintained Windows/Linux binaries; конкретную версию/checksum и CLI options должен проверить lead перед установкой.

Для Host routing официальный [origin parameter](https://developers.cloudflare.com/tunnel/reference/origin-parameters/#httphostheader) позволяет задавать HTTP Host header. Это настройка proxy, а не доказательство аутентичности caller. Не принимать чужие Forwarded/Host значения как trusted identity и не отключать TLS verification ради запуска.

## Минимальный конкретный interactive путь

Рекомендация — **один временный shared guided sandbox с ограниченной exclusive guest session**, а не новая multi-tenant platform. Все пользователи должны видеть, что это generated-signers localnet demonstration. Политика lease/session ниже — предложенный scope, не существующая функция.

1. **Изоляция.** Отдельный cwd safe source copy, new ignored `.local/public-demo/...` database/keys, новый validator ledger и свободные RPC/WS/faucet ports. Fixed public program ID загрузить из проверенного SBF at genesis; deployment keypair не нужен. Original ledger :8899 и original namespaces/signers не использовать, не reset/delete. Проверить genesis pin, program executable/hash и namespace до разрешения guest writes. Если отдельный validator не помещается в доступные RAM/CPU, interactive path остаётся blocked; перейти к явно read-only fallback вместо exposure owner API.
2. **Dedicated public-demo mode.** Обработчик по умолчанию disabled; в local-only режиме existing routes/semantics неизменны. Public instance слушает loopback отдельного app port; только его выдаёт tunnel. Native `/api/actions/prepare` и `/api/transactions/submit` в guest режиме возвращают explicit403. UI My wallet там отключён с понятной причиной; human-wallet success/cancel проверить владельцем отдельно на локальном app, не объявлять guided подпись человеческой.
3. **Exact HTTP gates.** Public hostname/origin хранить как один конкретный HTTPS URL, не `*.trycloudflare.com`. Until configured/public entry closed — deny API. Для всех methods проверять Host по ожидаемой proxy конфигурации; mutating guest requests требуют exact Origin, bounded JSON и CSRF token tied to server-issued Secure/HttpOnly/SameSite cookie. Отсутствующий/`null`/foreign Origin тоже deny в public mode. Не просто strip Origin at proxy.
4. **Guest capability.** Выдавать краткосрочную sandbox-only capability/exclusive writer lease; чужие session IDs, operation IDs, targets и serialized params не принимаются. One guest writer уменьшает взаимное разрушение демонстрации; observers могут читать same shared fixture. Напечатанные public/session credentials нельзя класть в repo/logs/URL/GitHub Pages. Optional email restriction использовать лишь после actual CLI/visitor verification.
5. **Серверные bounds.** Allowlist existing corporate-action types и четыре **новые** generated roles. Target bond/settlement mint/recipient должны принадлежать sandbox catalog; issuer/register/creation limits enforced **server-side**, не только hidden UI. Не добавлять arbitrary RPC/transaction/key/download endpoint. Сохранить body/UTF-8/idempotency/Ed25519/genesis/record/maturity/reconciliation guards. Предложенный small demo budget: one bootstrap +one issue per guest lease, at most30 distinct financial signatures, bounded outstanding requests/queue/lease; exact caps проверить на выбранном GUI lifecycle, чтобы не обрезать штатный сценарий.
6. **Сохраняем recovery.** Expired guest lease закрывает новые writes, но pending/unknown receipts, SQL и соответствующие generated signer files сохраняются. Не удалять keys/state и не seed/reset на каждом refresh. Same-ID replay/resume остаётся доступен своему гостю, новые financial intents блокируются при unresolved predecessor. Сброс sandbox — explicit operator action после проверки outstanding receipts, сохраняющий evidence.
7. **Public data surface.** `/api/health` sanitized; state/catalog содержит только sandbox data. GET operations/transactions ограничен session/sandbox known receipts, а не owner IDs. Static routes serve только built assets. Error/log redaction не скрывает реальный network/action/signature status. Private directory listings, environment/config/sqlite/keys endpoints отсутствуют.
8. **Tunnel readiness.** После локальных boundary tests можно на отдельный app port запустить verified official cloudflared. Сначала tunnel host вывести/проверить и точный origin включить; не выдавать unverified URL. Original API/RPC/WS/faucet не туннелировать. Проверить HTTPS из browser не той же машины/local-origin path: successful app flow и реальные backend receipt/state, а не один HTTP200.

В таком scope жюри сможет выбрать generated issuer, создать/обслужить sandbox issue, назначить holders/units/reserve, capture actual due record date, изменить позицию после capture, claim coupon, vote, open maturity redemption и получить actual burn/payment results. Waiting определяется real chain Clock; default accelerated record ~90s и maturity ~5min, а не подмена времени. UI не должен обещать доступный сейчас claim до due date. Если copy уже seeded, guided цикл работает сразу по его текущей фазе; для нового judge нужно explicit fresh issue/resume, не fabricated reset outcome.

## Узкие проверки перед разрешением public writes

- No-Origin/foreign-Origin/null-Origin/Host spoof/forwarded-header spoof denied; session/csrf отсутствует/чужой/истёк — denied. Same session successful action работает. Replay с тем же ID возвращает прежнюю подпись, conflicting ID/body rejected.
- Original issue/mint/role/recipient/operation ID отвергаются даже при valid generic syntax; original namespace/hash/evidence после sandbox cycle unchanged. Ни один public route не отдаёт fs path, `.env`, sqlite, ledger или private key bytes.
- Cap/queue/lease expiry не запускают вторую подпись при unknown outcome. Two browser sessions cannot both control exclusive writer; owner can recover after service restart without state loss. Test SOL only, local genesis identity remains verified.
- One complete **public HTTPS** guided lifecycle с exact sums, fees, actual signatures/context, final supply/vault; separate owner human-wallet sign/reject result. Не переименовывать mocked tests или локальный port smoke в public verification.
- Close/stop tunnel: public URL прекращает обслуживание; retained backend journals остаются. Pages video/source и instructions работают независимо от owner PC sleep/network/tunnel.

## Доступность и текущий blocker

Quick Tunnel зависит от включённого компьютера, сети, API/validator/cloudflared процессов; нет гарантии работы к асинхронному визиту жюри. Temporary URL нельзя подавать как единственный долгоживущий demo asset. На основной Pages разместить запись/код и, если временный sandbox действительно работает, честную secondary ссылку с проверенным временем и пометкой localnet. Потерю live доступа нельзя скрывать fallback toast/fake success.

Current assessment: **source/video release viable; direct owner API exposure rejected; isolated interactive path needs implementation and verification**. Бесплатный devnet rent пока не обеспечен, deployment signature отсутствует в изученном checkpoint. Не повторять429 faucets и не менять mainnet/paid bounds. Final submission/Terms remain owner-controlled.
